## 什么是 biubiu.tools？

biubiu.tools 是一个全面的 Web3 工具套件，旨在简化区块链开发和运营。无论您是部署智能合约、管理代币，还是执行批量操作，biubiu.tools 都能提供您所需的工具。

## 核心功能

### 智能合约部署

通过我们直观的界面，在多条链上部署 ERC20 代币、NFT 和自定义智能合约。

- **代币部署器**：创建和部署具有可定制功能的 ERC20 代币
- **NFT 部署器**：发布支持元数据的 NFT 集合
- **合约部署器**：轻松部署任何经过验证的合约

### 钱包操作

高效管理多个钱包并执行批量操作。

- **代币余额扫描器**：检查多个钱包的代币余额
- **钱包归集**：从多个钱包归集代币
- **一对多转账**：向多个收款人分发代币

### 开发者工具

专为区块链开发者和高级用户设计的工具。

- **合约事件扫描器**：监控和分析智能合约事件
- **Call Master**：向任何合约发起自定义 RPC 调用
- **链列表**：快速访问链配置
