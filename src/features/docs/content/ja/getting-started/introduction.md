## biubiu.tools とは？

biubiu.tools は、ブロックチェーン開発と運用を簡素化するために設計された包括的な Web3 ツールキットです。スマートコントラクトのデプロイ、トークンの管理、バルク操作の実行など、必要なツールを提供します。

## 主な機能

### スマートコントラクトのデプロイ

直感的なインターフェースで、複数のチェーンに ERC20 トークン、NFT、カスタムスマートコントラクトをデプロイできます。

- **トークンデプロイヤー**：カスタマイズ可能な機能を持つ ERC20 トークンの作成とデプロイ
- **NFT デプロイヤー**：メタデータをサポートした NFT コレクションのローンチ
- **コントラクトデプロイヤー**：検証済みの任意のコントラクトを簡単にデプロイ

### ウォレット操作

複数のウォレットを効率的に管理し、バルク操作を実行します。

- **トークン残高スキャナー**：複数のウォレットのトークン残高をチェック
- **ウォレットスイープ**：複数のウォレットからトークンを集約
- **一対多送金**：複数の受取人にトークンを配布

### 開発者ツール

ブロックチェーン開発者とパワーユーザー向けに設計されたツール。

- **コントラクトイベントスキャナー**：スマートコントラクトイベントの監視と分析
- **Call Master**：任意のコントラクトへのカスタム RPC 呼び出し
- **チェーンリスト**：チェーン設定への素早いアクセス
